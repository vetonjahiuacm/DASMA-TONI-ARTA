# Galeria e Fotove – Vetoni & Arta

Vendos fotot e çiftit direkt në KËTË folder:
`/app/frontend/src/assets/gallery/`

Formatet e pranuara: **.jpg, .jpeg, .png, .webp, .gif**

Sapo t'i vendosni fotot këtu, ato shfaqen **AUTOMATIKISHT** në seksionin
"Momentet Tona" të faqes — pa asnjë ndryshim tjetër në kod dhe pa buton ngarkimi.

Renditja bëhet sipas emrit të skedarit, prandaj mund t'i emërtoni:
`01.jpg`, `02.jpg`, `03.jpg` ... për t'i renditur si të doni.
